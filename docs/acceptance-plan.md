# План приёмки: что проверить руками на своей машине

Всё ядро аддона покрыто тестами (262 прогона), но **ни Anki, ни Qt в среде разработки не было**.
Ниже — то, что проверить можно только на живой Anki. Формат: сделать X — увидеть Y.

## 0. Установка и запуск

1. Положить папку `anki_sentence_cards` в каталог аддонов Anki, перезапустить Anki.
   → В меню **Tools** появилось подменю «Anki Sentence Cards» с пунктом «Настройки». При старте нет ошибок.

## 1. Настройки

2. Открыть настройки.
   → Выпадающие списки колод и типов заметок заполнены, фильтрованных колод нет, окно не падает.
3. Выбрать колоду и тип заметки, сохранить, открыть заново, перезапустить Anki, открыть снова.
   → Значения на месте.
4. Добавить файл книги; добавить второй; выбрать активный; сохранить; открыть.
   → Активной остался выбранный. Удалить активную → активной стала первая оставшаяся. Повторно добавить тот же файл → дубля нет.
5. Tools → Add-ons → Config: дописать `"x": 1`, затем сохранить настройки из окна аддона.
   → Ключ `x` на месте.
6. Испортить конфиг (`"occurrence_limit": "abc"`, `"books": null`, `"occurrence_limit": Infinity`).
   → Окно настроек **всё равно открывается**, значения заменены умолчаниями.

## 2. Сопоставление полей

7. Тип заметки с нестандартными именами полей → сохранить.
   → Экран ручного сопоставления открылся сам.
8. На экране сопоставления поставить «не заполнять» для `front` и нажать OK.
   → Предупреждение, окно не закрывается. Крестик/Esc/Отмена — выпускают.
9. Выбрать тип A, сопоставить вручную, OK, Сохранить, открыть заново.
   → Выбор на месте.
10. Тип A сопоставлен → выбрать тип B → «Сопоставить вручную» → **Отмена** → вернуть на A → Сохранить → открыть сопоставление.
    → Карта A цела, включая «не заполнять».
11. Поставить «не заполнять» для `translate`, сохранить, создать карточку.
    → Поле Translate на карточке пустое; при следующем открытии «не заполнять» по-прежнему выбрано.
12. Выбрать **одно и то же поле** для двух ключей (например `Meaning` для `meaning` и для `pos`), OK.
    → Предупреждение о коллизии, окно не закрывается.
13. Обновление с прежней версии: конфиг с плоским `field_map` и `notetype`.
    → Сопоставление то же, что было, экран сам не открывается.

## 3. Первая карточка

14. Создать одну карточку через аддон.
    → Нужная колода; заполнены Front, Translate, Type of word, Transcription of word, Meaning, Sound of word; **`Sound of sentence` и `Notes` пустые**. Сверить с карточкой, сделанной руками.
15. В браузере карточек посмотреть теги.
    → У всех `asc`; у карточки с заведомо отключённым источником ещё и `auto-incomplete`; у полностью успешной — только `asc`.
16. Проиграть звук на карточке.
    → Звучит нужное слово, голос британский (переключается в настройках).
17. Отключить ключ `sound` в сопоставлении и прогнать партию.
    → Карточки созданы, **лишних mp3 в папке media не появилось**, строки про звук в отчёте нет.

## 4. Поиск слова в книге

18. PDF с переносом слова через дефис на границе строки.
    → Слово находится, предложение целое, без разрыва.
19. Слово с типографским апострофом, скопированное из электронной книги (`don’t`, `O’Brien`).
    → Находится.
20. Частотное слово в большой книге.
    → Список открывается без заметной паузы; **точная форма стоит первой**; видно «показаны первые N».
21. `can` в книге, где есть `candle` и `can't`.
    → Найдено только настоящее `can`.
22. Слово, которого в книге нет.
    → Явное сообщение, предложен ручной ввод предложения и пропуск; молча не пропускается.
23. Выбор предложения **цифрой с клавиатуры**, когда фокус в списке.
    → Работает. Если нет — сказать мне, чинится фильтром событий.

## 5. Партия и отчёт

24. Партия из 10-20 слов.
    → Anki не морозится, виден прогресс.
25. Во время сборки нажать Esc и крестик.
    → Окно не закрывается; после отчёта закрывается нормально.
26. Во время сборки посмотреть на страницу ввода.
    → Кнопка «Начать» неактивна; после отчёта снова активна.
27. Во время сборки закрыть профиль (File → Switch Profile).
    → Сообщение «Профиль закрыт, партия не записана», без аварийного окна и зависания.
28. Партия, где одно слово заведомо проблемное → «Повторить проблемные» → завершить повтор.
    → В итоговом отчёте и созданные из первого прогона, и результат повтора; ни одно слово не названо дважды.
29. Слово, которое уже есть в колоде (например `run` при карточке «I run every day»).
    → Отмечено как дубликат, вторая карточка не создана. Слово `art` при карточке со словом `part` дубликатом **не** считается.
30. Имя колоды с `_`, `*`, `::` или `\`; слово с `:` или `\`.
    → Поиск дубликатов не падает, ищет в нужной колоде.

## 6. Источники (то, что проверить было нечем)

31. Неверный ключ DeepL → прогнать партию.
    → Перевод пришёл от Google, **в отчёте вверху предупреждение**, что DeepL отказал.
32. Настоящий PDF на Windows.
    → Книга загружается. Если нет — скорее всего дело в версии `typing_extensions` внутри Anki, скажи мне.
33. Значение слова на нескольких карточках.
    → Пришло из Reverso в привычном формате. Если формат «съехал» — вёрстка Reverso сменилась, чинится в одной функции `_parse_reverso` в `sources/meaning.py`.
34. Часть речи и транскрипция.
    → Те, которые ты выбрал во втором проходе; транскрипция без слешей.

## Второй проход: роль слова и значение

35. Слово `record`.
    → Две кнопки роли, `noun` и `verb`; при переключении меняется транскрипция рядом с кнопкой.
36. Слово `run`.
    → Три кнопки роли, а не четыре (`verb` не повторяется), и одна и та же транскрипция у всех трёх.
37. Слово `supervised`.
    → Роль помечена `(от supervise)` и стоит ниже ролей самого слова.
38. Слово с одной ролью и одним значением, например `house`.
    → Второй проход его не показывает вовсе, карточка создаётся сразу.
39. Фраза `get along`.
    → Кнопок роли нет, список значений есть; в `Type of word` — `phrase`.
40. Клик по другой кнопке роли.
    → Список значений перерисовался (английская часть другая), слово и счётчик не сменились.
41. «Принять всё» на пятом слове из двадцати.
    → Карточки создались сразу, в полях первые варианты, показан отчёт.
42. Партия из двадцати слов.
    → Перерыв не дольше двух минут, Anki в это время не морозится.
43. Закрыть окно посреди перерыва — Esc или крестик.
    → Anki жив, показано «Перерыв прерван…», уже добытые карточки записаны, остальные в отчёте как необработанные.
44. «Отмена» в прогресс-диалоге Anki посреди перерыва.
    → То же, что в 43.
45. Снять галку «Добывать транскрипцию из Wiktionary» и собрать партию.
    → Карточки создаются, транскрипция может быть пустой, в отчёте нет ошибок про Wiktionary.
46. Выставить «Слов за раз (перерыв)» в 1 и собрать три слова.
    → Перерыв заметно дольше, карточки те же. Значение 0 или 99, вписанное в конфиг руками, зажимается в 1..8.
47. Слово, у которого словарь дал роли, а значение не добылось.
    → В списке значений одна строка «значение не добыто — подтвердить и идти дальше»; после клика слово проезжает, поле `Meaning` пустое, причина в отчёте.

## Что заведомо не проверено

- Вид окон: ширина, высота строк в списке предложений, переносы длинных путей.
- Поведение на очень большой книге в сочетании с очень частотным словом.
- Формы ответов Google-переводчика и словаря: сверены с документацией только для DeepL.
- Раскладка страницы второго прохода: длинные строки значений, перенос кнопок ролей при четырёх и более ролях.
